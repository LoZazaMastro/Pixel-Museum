# Pixel Museum

**You remember the feeling.**

The games we played. The world we grew up in. An independent, interactive museum for PS5.

This private repository is being prepared for publication. No public release is available yet, and GitHub Pages has not been enabled.

The website, selected English app captures, teaser and installation guide are in preparation. The app build is tested and transferred separately; development credentials and personal configuration do not belong in this repository.
