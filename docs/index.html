How to install
  1. Download every archive part from the same release into one folder. Open the first part in 7-Zip and extract it.
  2. Enable FTP on your PS5, then copy the entire PPSA70421 folder into /data/homebrew/.
  3. Open Pixel Museum from your homebrew launcher.
