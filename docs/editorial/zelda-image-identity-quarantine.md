# Zelda image identity quarantine

All three inherited MinishCap-named files were inspected at their original Playhub paths and fully decoded; hashes match the prior catalogue. They show an optical apparatus, a real suspension bridge and a D-Link CardBus network adapter. None is a Zelda image. The misleading filename and Nintendo source links cannot establish either subject identity or photo rights.

The additive JSON lists exact URL removals for root, archives every original image record unchanged, and records actual file hashes/dimensions. Do not relabel them as The MinishCap or redistribute them under an invented Nintendo attribution. No master/package/source file has been altered. Replacement is a separate source acquisition.
