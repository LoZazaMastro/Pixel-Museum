# Technical checkpoint review

The audit found two concrete lifecycle problems and corrected them. Model request/cancel/stop now invalidates the request generation and retires pending model/image mailboxes in one mutex transition. Previously the worker could publish the old result between these operations. Large CPU buffers still retire on the worker, and GPU objects still drain through the bounded main-thread queue. Video open/close also clears queued pause and seek commands, preventing controls from the previous recording from being inherited.

Targeted tests passed: 32 cancellation/publication rounds with a neutral model and another 32 with an authored texture; two real textured poses at 3840 × 2160 with GL-state restoration; both 4K silhouette-AA checks; and 32 caption selection, timing, malformed-input and cancellation cases. Isolated syntax compilation using the actual native build flags plus `-Werror` passed for ObjectScene and Video. No Ninja, full link or preview build was run. Receipts are `build/checkpoint-{object-cancel,object-textured-4k,object-aa,captions,tech-native}.log`, with source/log SHA-256 values in `build/checkpoint-technical-review.json`.

The existing media contract was checked in the actual call path: default gain is 0.6 in both Screen and Video; L2/R2 adjusts the separate media gain during film or active soundtrack playback; playlists open the native player with audio-only enabled. Captions prefer an exposed direct language track, otherwise an advertised translation, follow the decoder clock and remain disabled for audio-only playback. These are code-path and controlled-fixture checks, not successful live YouTube or physical speaker tests.

Original model geometry, 4096-pixel maps, sampler/material handling and native output size are unchanged. This bounded audit did not repeat the heavyweight full Game Boy run; its earlier full-resolution receipt remains in `model-streaming-optimization.md`. Two milliseconds is a scheduling budget, not a guaranteed maximum duration of a driver allocation/deletion. The current fixture timings come from desktop Mesa llvmpipe and must not be treated as PS5 GPU performance. Physical memory residency, loading latency and any accepted 120Hz mode still require actual console evidence. No console or package files were changed.
