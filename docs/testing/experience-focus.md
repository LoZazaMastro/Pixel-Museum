# Pausing the active experience safely

Screen now owns a uniform focus gate for all 21 reviewed studies. Losing focus or disconnecting stops study updates. Returning while a button, stick, trigger or touch is still held keeps the experience suspended; one genuinely neutral sample rearms it. That sample also drains deferred study feedback privately, so the last collision or note from before suspension cannot be replayed as a new event. The synthetic-note branch of `take_startup_note` discards notes while the experience is paused; the museum entrance sequence is unchanged.

The rhythm study needs an audio-clock pause as well as a physics pause. `ExperienceAudio::paused` leaves another mixer source's stereo samples untouched, writes zero to its own controller-speaker buffer, and preserves oscillator/noise/sample phase. Resuming fades back in from the same sample instead of restarting the musical phrase. Stopping while paused never restarts it. These are callback-boundary checks; physical PS5 buffering latency is unmeasured.

Run `bash tools/preview.sh experience-focus` for the actual Screen/GL regression. It constructs all 21 production studies, delivers active and then hostile focus-lost controls, verifies sixty suspended updates/audio callbacks, checks held-input and neutral-rearm behavior including deferred notes/haptics, resumes each session and closes it normally. The existing `experiences` harness also passes onboarding, navigation, playlist rooms, source-card return and real GL rendering. The standalone `tests/run-experience-audio.sh` verifies additive audio mixing, sample-clock pause/resume/stop and the original beat/buffer-invariance/loop tests.

Video and soundtrack playback state are separate. No play/resume calls were added to those engines. The host checks preserve listening-room selection and an idle media engine; native paused video playback remains a PS5 verification item. Evidence and source hashes are in `build/research/experience-focus/verification.json`. No FTP transfer was performed.
