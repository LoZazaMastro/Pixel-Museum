# A collection you can move through

The chronology is one continuous scene. Focusing an exhibit previews it immediately. Opening it lifts the same timeline into the top bar and unfolds a sequence of cards below. A photograph, film, object or short narrative leads each card. The original prose is still available with Square; it is not squeezed into a smaller font to fit the stage.

Left and right move between cards. L1 and R1 move between exhibits while a story is open. The selected card owns its media action. Returning from an image, film or 3D inspection keeps that card and its reading position. Unillustrated stories remain honest typographic compositions rather than receiving unrelated images or fabricated quotations.

Touchpad opens the Year Atlas on the left. A continuous curved index moves around the selected year, with the number of exhibits and the first stop in that year. X goes to that first stop; L1 and R1 move between decades. Triangle from the timeline goes directly to today's discovery in the same collection. The calendar is scheduling metadata, not proof of an event's historical date.

Known dates show day, month and year. Region qualifiers distinguish launches where appropriate. Year-only or month-only sources retain that precision. Separate reveals, regional launches, first public versions and reissues keep separate historical identities.

The first visit runs on black before the M introduction. Four short animated panels introduce the collection and its controls. The final centred Options prompt must be acknowledged before the M animation starts. Completion is saved in preferences; Replay introduction is available in Museum options. Skip introduction skips the explanation, not the Options gate. Reduced motion keeps the information and short fades while removing decorative movement.

An original pixel workshop accompanies selected early exhibits. Its eight-by-eight drawing and four shades are an educational illustration, not a running historical game. It has explicit entry/exit and cannot move the chronology while editing. No copyrighted game artwork is included in the exercise.

## Rendering and sound

Console entries present their model directly when it is ready. They do not first show a photograph of another view. Texture decoding, mip generation and large cancelled CPU allocations run on the worker. GPU transfer and retirement are split across UI ticks. The retained 3D texture can be reused while the interface animates; automatic rotation does not require a fresh render on every UI frame. Hero and inspected targets match their on-screen pixel footprint at a 4K output. Original maps and geometry are retained.

Soft wall projections are cached at a lower resolution because they contain only broad, low-opacity light fields. Text, photographs, the interface and 3D objects keep their own full-resolution rendering paths. CPU and asynchronous GPU timings are diagnostic evidence, not a guarantee of console frame rate. Each allocation is still a driver call that cannot be preempted halfway through.

All eight musical arrangements share the same continuous sample position. Selecting a decade begins a 200 ms constant-sum crossfade on the next audio callback. Mute and films do not reset that position. Each decade has a distinct arrangement of the same harmonic phrase. The interface palette follows the selected decade with a separate smooth fade.

## Experiences

Twenty original interactive studies and the existing pixel workshop are gathered in the left guide. Touchpad opens the guide; Square switches between Years and Experiences. Each study is also inserted into its linked exhibit. Returning preserves the source card or library selection.

Every launch begins with a dedicated explanation and an explicit Begin action. Introductions identify a concrete game-design, art-direction or musical idea, connect it to the historical work and explain the controls. Completion is not saved as permission to skip this explanation on later visits.

The studies use bounded procedural vector geometry and original minimal musical cues. They do not execute original game code or distribute original game music. All twenty have separate mechanics rather than reskinned generic effects. Space, motion and arcade groups have focused interaction, reset, blocked-input, nonfinite-time and bounded-geometry checks, plus actual 3840?2160 host renders. These tests do not establish physical PS5 frame rates.

Optional motion controls are enabled explicitly with Triangle in supported study introductions. Each launch calibrates a comfortable neutral accelerometer direction. Sticks remain available, and missing sensor readings leave conventional controls intact. The pixel workshop accepts a normalized touchpad position and click-to-shade. Short event rumbles use the existing pad output. The microphone is not activated: the pinned SDK does not provide a verified typed input path. Sensor decoding/layout tests are separate from physical controller validation. See research/controller-sensors.md for the local reference and limitations.

## Listening cards

Journey, Celeste and Final Fantasy VII have curated official YouTube recordings. Up and Down select a track, Cross plays or pauses, and Square expands the same frame. Audio belongs to the current exhibit, continues while browsing its cards, and stops when another exhibit is selected. An archival film takes exclusive ownership of the single native video engine. Only actual engine progress, duration and playback states are displayed. Attribution remains in Sources and the content credit inventory. Host tests verify routing and ownership without claiming successful network streaming.


## Native composition and object resolve

The second console trace exposed two software fallback paths absent from the host results: a 4K framebuffer blit in every settled frame, and an MSAA framebuffer resolve for each model render. The UI and entry snapshots now sample scene textures with GPU draws. Fully opaque experiences use a separate retained draw list and render without drawing the hidden collection underneath. Snapshot orientation, opaque colour and interrupted-dissolve continuity are covered by production-screen 4K pixel tests; rendering counters reject framebuffer blits and CPU pixel readbacks.

Objects retain their requested pixel dimensions, geometry and original texture maps. A single-sample full-resolution sRGB scene is passed through a GPU silhouette-coverage filter. This avoids the native MSAA fallback while preserving exact opaque lettering and artwork; it does not claim geometric multisampling or smooth every internal material edge. The revised path passes material, alpha, state-restoration and actual4K object tests. New startup phase logs distinguish display, fonts, catalogue, music and first-frame timing. Physical PS5 frame rate must be measured after deployment.


## Navigation sound

The dedicated `assets/audio/museum-navigation/glass` bank uses short original cues in the score's D-minor/modal palette. Focus, selection, back, decade changes and panels have distinct quiet gestures. Source UI recordings remain intact as a fallback. The new index is shipped with the bank so the native `/app0` file listing can discover it. Museum playback disables the generic bank's random pitch jitter to retain the intended musical tuning; the generic library default remains unchanged. Clips are decoded before the audio callback starts.
